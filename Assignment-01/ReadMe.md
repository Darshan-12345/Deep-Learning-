# Assignment 01 - CIFAR-10 Image Classification

## Objective

To classify CIFAR-10 images using an Artificial Neural Network.

## Dataset

CIFAR-10 dataset contains 60,000 color images belonging to 10 classes.

### Classes

- Airplane
- Automobile
- Bird
- Cat
- Deer
- Dog
- Frog
- Horse
- Ship
- Truck

## Model

Artificial Neural Network (ANN)

## Technologies Used

- Python
- TensorFlow / Keras
- NumPy
- Matplotlib

## Dataset Link

CIFAR-10 Dataset:
https://www.cs.toronto.edu/~kriz/cifar.html
